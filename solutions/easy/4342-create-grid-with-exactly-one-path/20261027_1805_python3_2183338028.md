## Solution

```python
from typing import List

class Solution:
    def createGrid(self, m: int, n: int) -> List[str]:
        g = [["#"] * n for _ in range(m)]

        g[0] = ["."] * n

        for i in range(m):
            g[i][n - 1] = "."

        return ["".join(row) for row in g]
```
