# LeetCode Submissions Archive 📚

A personal archive of my LeetCode solutions, automatically synchronized from LeetCode to GitHub using [LeetCode Cloud Sync](https://github.com/kaviyack/leetcode-cloud-sync).

This repository keeps my accepted coding submissions organized, searchable, and version-controlled.

## 📂 Repository Structure

Solutions are organized by difficulty and problem:

```text
solutions/
├── easy/
│   └── problem-slug/
├── medium/
│   └── problem-slug/
└── hard/
    └── problem-slug/
```

Each solution is stored with relevant submission information, including:

- Problem title and LeetCode link
- Unique submission ID
- Programming language
- Submission status
- Submission timestamp
- Runtime and memory statistics, when available
- Topic tags, when available
- Submitted source code

## 🤖 Automatic Synchronization

This archive is maintained using **LeetCode Cloud Sync**, an open-source automation project.

The system periodically checks for new accepted submissions and synchronizes them to this repository through Cloudflare Workers, Cloudflare Queues, and GitHub Actions.

**Main project:** [LeetCode Cloud Sync](https://github.com/kaviyack/leetcode-cloud-sync)

## 🎯 Purpose

This repository serves as:

- A personal record of coding practice.
- A searchable collection of problem-solving approaches.
- A version-controlled history of submitted solutions.
- A way to track consistency and progress in problem-solving.
